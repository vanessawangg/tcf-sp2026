# Pre-work: The Professional Toolkit

**Objective**: Before our session on Professional Development, we want you to start thinking about your career "story" and get your digital presence ready.

## 1. The Resume Mindset: Impact over Duties

Most students write resumes that look like job descriptions: "Responsible for fixing bugs."
Recruiters want to see **impact**: "Reduced crash rate by 20% by fixing critical memory leaks."

**Read**:

- [Google's Resume Tips](https://www.youtube.com/watch?v=BYUy1yvjHsk) (Video, 2 mins)
- [The STAR Method](https://www.vawizard.org/wiz-pdf/STAR_Method_Interviews.pdf) (Situation, Task, Action, Result) - This is crucial for both resumes and interviews.

## 2. Technical Interview Prep

We will be discussing "NeetCode" and "LeetCode". These are platforms for practicing data structure and algorithm questions, which are standard in software engineering interviews.

**Explore**:

- [NeetCode.io](https://neetcode.io/) - Look at the "NeetCode 150" list.
- [Blind 75](https://leetcode.com/discuss/general-discussion/460599/blind-75-leetcode-questions) - The classic list of must-know problems.

## 3. Behavioral Questions

Technical skills get you the interview; soft skills get you the job. You need to be ready to answer questions like "Tell me about a time you failed."

**Think about**:

- A project where things went wrong.
- A time you had a conflict with a teammate.
- A time you showed leadership (even if you weren't the "leader").
